# @maple/task-surface

English | [中文](README.zh.md)

Declarative Task Surface domain, schema validation, session projection, and host service for structured human-agent interaction.

## Model Experience

None, as this shared domain and projection host registers no model-visible context; the tool-task-surface package and UI renderers own rendered effects.

#### KV Cache effect

No direct invalidation; this package does not contribute request tokens.

## Known Limitations and Deferred Work

- Version 1 supports static declarative models without client-side arbitrary script evaluation.
