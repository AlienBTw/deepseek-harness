# Agent Note: 工具可达能力 seam 中的必填取消

Status: implemented

[English](2026-07-19-required-cancellation-through-tool-capability-seams.md) | 中文

## 问题

已经实现的[工具注册表取消约定](./2026-07-19-cooperative-tool-cancellation.zh.md)让每个工具主体中的 `exec.signal` 成为必填值，但许多从这些工具主体可达的异步能力接口仍接受可选信号。因此，工具可以满足自身类型，却在下一次同进程调用时意外丢失取消。

这一缺口会沿调用链传递。文件系统工具可能调用路径解析和 I/O，Web 工具可能调用提供方，Bash 工具可能调用执行器，组合工具可能启动或等待任务、subagent 或工作流。只要某个控制工具所持有的工作且会被工具等待的操作允许省略信号，TypeScript 就无法证明取消仍能到达拥有副作用的边界。

要求仓库中所有异步函数都携带信号会过度扩张。有些操作无法从工具到达，有些同步查询无法等待或持有持续工作，而明确分离的工作在刻意交接后已经拥有新的所有者。

## 决策

所有能从工具主体到达、且在工具仍持有或等待该操作期间执行的异步同进程能力操作，都必须接收 `AbortSignal`。根据所属 seam 的既有形态，这项要求可以表现为位置参数，也可以表现为必填的只读请求字段，但省略信号必须导致 TypeScript 编译失败。

每个直接调用方提供自己持有的信号，或从自身必填的操作上下文继续传递信号。实现可以派生子截止时间或取消作用域，但派生信号在委托期间仍须与上游信号关联。能力实现不得生成永不中止信号、使用环境式异步本地取消，也不得仅为重复类型化同进程约定而在运行时校验 `AbortSignal`。

### 延期家族

工作流、subagent、code-runtime、jobs／task 等待及类似工具可达 seam 仍按完整 Service Definition／Provider／Consumer PR 迁移。下方范围边界仍然适用。

### 范围边界

决策覆盖完成或取消仍属于调用工具生命周期的异步能力操作，包括所有权交接前的启动、前台执行、读写、提供方请求、等待，以及工具会等待的清理或处置。

决策排除同步注册表查找、可用性检查、schema 渲染、参数分类等无法持有异步工作的操作；也排除明确分离所有权交接之后的工作：任务、工作流、worker 或子代理一旦成功发布给新的生命周期所有者，就由该所有者的控制器管辖分离后的寿命。启动操作在交接提交前仍须携带调用方信号；之后任何等待分离工作的工具调用须使用自己的调用信号。

当外部协议允许可选取消时，解析器、配置、模型／工具 JSON、持久／文件格式、worker、进程或线路输入可以保留可选取消。所属边界在调用已迁移的能力 seam 之前，必须把该输入解析为必填的同进程信号。

## 曾考虑的替代方案

**因工具主体已收到信号而让下游信号保持可选。** 已否决：外层回调可用并不能让传播在类型上安全；每个可选能力调用仍可合法省略。

**用 lint 或回调检查强制传播。** 已否决：语法检查无法可靠识别所有权、派生信号、抽象层或正确的静止结算。必填接口参数把约定放在 TypeScript 能检查每个调用方的位置。

**把 `ToolRunContext` 传给每个能力。** 已否决：能力需要的是取消，而不是工具身份、智能体状态或上下文延期。传递更大上下文会把可复用服务耦合到工具注册表，并模糊窄 seam。

**使用环境式异步本地信号。** 已否决：隐藏传播使所有权与分离交接难以审计，复杂化测试，并可能让调用静默绑定到错误寿命。

**在能力实现处添加默认或永不中止信号。** 已否决：默认会抹掉缺失的所有者，而不是在编译期暴露它。

**在已实现的工具注册表变更中迁移所有能力。** 已否决：传递式接口变更跨越独立能力家族。保持本决策独立可保留已实现的注册表决定，并让每个深层 seam 用聚焦测试迁移。

## 后果

- 文件系统、shell 与 web 的工具可达等待要求 `AbortSignal`，并有编译期省略测试。
- 其余家族在预发布立场下迁移时不保留可选兼容重载。
- 进程、worker、套接字、提供方与任务边界上的集成测试仍须证明观察与静止，而不仅是类型可用性。
